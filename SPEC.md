Write a Python 3 crypto PAPER-TRADING project (simulation only, NEVER real orders, no API keys). Only dependency: requests. Files: run.py, pt/__init__.py, pt/data.py, pt/strategies.py, pt/sim.py, .gitignore (.venv, __pycache__), requirements.txt, README.md in Spanish (stress: simulación, sin dinero real).
- data.py: fetch closed 4h klines from https://api.binance.com/api/v3/klines (fallback https://data-api.binance.vision) for BTCUSDT, ETHUSDT, paginating with startTime, limit 1000; drop candles whose close_time > now. Cache to data/klines_<SYM>.csv. Fetch USDT/ARS from https://criptoya.com/api/usdt/ars/1 (median of 'ask' values), fallback 1450.
- strategies.py: signal functions over close/high/low arrays returning target exposure 0..1 per bar using ONLY data up to that bar: (1) ema_cross: EMA20>EMA50 and close>EMA200 -> 1 else 0; (2) rsi_mr: RSI14<30 and close>SMA200 enter, exit RSI>55; (3) donchian: close>prior 20-bar high enter, exit close<prior 10-bar low. Risk: max position 95% of equity per pair sleeve, stop-loss 5% below entry (checked on bar low, exit at stop price), after a stop wait for fresh entry signal.
- sim.py: portfolio split 50/50 between BTCUSDT and ETHUSDT sleeves per strategy. Trades executed at next bar open (signal on bar t close, fill at t+1 open). Fee 0.1% per side, slippage 0.05% adverse. Baselines: buy&hold BTC, buy&hold 50/50 BTC-ETH (pay fee+slip once). Metrics: final equity, return %, max drawdown %, number of trades.
- run.py commands:
  backtest [--days 730] [--capital 1000]: run each strategy and baselines over full period, and also split: in-sample first 70% / out-of-sample last 30% (report separately, params fixed, no optimization). Print markdown tables. Save to data/backtest_results.md.
  tick: idempotent live paper mode. State in data/state.json (start_time, usdt_ars rate, capitals: ARS 10000 converted to USDT and also a 1000 USD track; per strategy per sleeve cash/qty/entry/stop/last_processed_open_time; baselines). On first run initialize: record start time and prices, buy baselines at latest close; set last processed = latest closed candle (no history replay). Subsequent runs: fetch latest closed 4h candles, process only candles with open_time > last processed, in order, applying the same logic (needs ~250 bars lookback for indicators). Append each trade to data/ledger.csv and an equity snapshot per tick to data/equity.csv. Use file lock (fcntl) for safety.
  report: print table per strategy and baselines for both capital tracks: equity, return % since start, max drawdown % (from equity.csv), trades, start date.
Keep code clear and tested by actually running `.venv/bin/python run.py backtest` at the end.
